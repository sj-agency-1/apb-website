# Финансовое планирование для личного бренда

Как правильно распределить бюджет на продвижение?

## Правило 70/20/10

- **70%** — проверенные каналы, которые уже работают
- **20%** — новые инструменты с потенциалом роста
- **10%** — эксперименты и тестирование гипотез

## ROI каждого канала

Отслеживайте возврат инвестиций по каждому каналу продвижения, чтобы оптимизировать расходы.
